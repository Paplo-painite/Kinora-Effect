# Security Policy

## Supported releases

Security fixes are prioritized for the latest public release. Users should keep Kinora Effect updated through the official GitHub Releases page.

## Reporting a vulnerability

Please do not disclose an unconfirmed security vulnerability in a public issue. Contact the repository owner privately through the GitHub profile or repository security contact, and include:

- A concise description of the issue.
- The affected release and device environment.
- Reproduction steps or a proof of concept that does not expose private data.
- Any suggested mitigation.

Please allow maintainers reasonable time to investigate and prepare a fix before public disclosure.

## Safe reporting

Never include passwords, private media, signing keys, access tokens, or personal information in issues, logs, screenshots, or sample projects.
